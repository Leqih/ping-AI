# Ping AI: UI/UX design assignment

Interactive web prototypes of Ping, a consumer AI app where specialist "Insiders" watch for openings (tables, tickets, drops, market moves) and act for you with your confirmation.

| Version | Folder | What it is |
| --- | --- | --- |
| **New** | [`new/`](new/) | Updated prototype aligned with Ping's new App Store preview: photo-story Today feed, confirm-before-grab sheet, task pages with live progress, Insider chats with autonomy settings, richer Markets flow, motion pass. |
| **Old** | [`old/`](old/) | The original assignment prototype, kept for comparison. |

Each folder also has a `rationale/` page with design notes.

## Run locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000/new/ or http://localhost:8000/old/
```

The prototypes are static HTML; open them through a local server (not `file://`) so the images and video load.
